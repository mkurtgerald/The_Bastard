# Bundled binary source and license references

The generated BUNDLED-BINARY-SOURCES.json records the exact executable versions and SHA-256 hashes. The build runs each bundled media executable with `-L` and `-version`, saves its actual license statement and build configuration, and includes the full GPLv3 text separately for FFmpeg and ffprobe. It fails rather than silently accepting a different license. Npm wrapper licenses do not replace executable licenses.

- FFmpeg is obtained through pinned ffmpeg-static 5.2.0, release b6.0: https://github.com/eugeneware/ffmpeg-static/releases/tag/b6.0 . That package identifies Gyan's Windows x64 builds: https://www.gyan.dev/ffmpeg/builds/ . Its downloaded binary README/license are retained under licenses/ffmpeg-static when supplied upstream.
- ffprobe is obtained through pinned ffprobe-static 3.1.0. Its package documentation identifies FFmpeg 4.0.2 and the historical Zeranoe Windows builds. The wrapper/project source is https://github.com/derhuerst/ffprobe-static . Zeranoe's original build service is retired; the package README is retained, and the binary's actual version, license and configuration are recorded rather than treating the wrapper's MIT license as the binary's license.
- FFmpeg's official source releases are indexed at https://ffmpeg.org/releases/ . The machine-readable manifest points to the version-specific source archive for each executable. Licensing guidance: https://ffmpeg.org/legal.html . Build flags and incorporated third-party libraries can change obligations.
- Node's complete distribution LICENSE, including bundled third-party notices, is retained as licenses/NODE-LICENSE.txt. Its exact version source archive is referenced in the manifest under https://nodejs.org/dist/ .
- SQLite's Node binding retains its installed package source files and license text under native-evaluation/node_modules. SQLite source is included under sqlite3/deps, in addition to the binding's source/license. Its upstream references are in the manifest; other npm packages retain their own source/license files as installed by the lockfile. The unused PAM/pixel-change motion addon is excluded from this evaluation runtime; the original non-evaluation import behavior remains in the source.

These references and notices are minimum provenance evidence, not a completed corresponding-source compliance package or commercial-license clearance. Exact source/build correspondence for every incorporated third-party component still requires release review. No proprietary license rights or permission to remove upstream notices is asserted. The original camera component's separate and conflicting license notices remain preserved.
